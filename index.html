FAQ

Is PingStatus safe and lightweight?

Yes. It runs efficiently in the background using native macOS networking. No unnecessary permissions or data collection.

Can I customize alerts?

Fully. Set thresholds for latency, packet loss, jitter. Disable specific metrics. Notifications only on real changes.

No. Defaults work out of the box. Fine-tune in Settings → Thresholds if desired.

How do I view history?
